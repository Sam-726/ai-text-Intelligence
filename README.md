# AI Text Intelligence

A Master's-level NLP/ML project exploring how machine-learning models can learn patterns in written text.

The current focus is a simple research question:

> Can a machine-learning model distinguish between human-written and AI-generated text?

The goal is to build the project step by step, understand the modelling choices, compare approaches, and document where the models work and where they fail.

## Current version

The first milestone contains:

- TF-IDF text representation
- A small set of interpretable writing-style features
- A Linear SVM classifier
- Accuracy, precision, recall, F1-score and ROC-AUC evaluation
- A small synthetic demonstration dataset
- Unit tests for the feature and modelling code
- A simple Streamlit interface

This is an educational portfolio project, not a reliable AI-content detector. The demonstration dataset is intentionally small, and results should not be treated as evidence that the model can reliably identify AI-generated text in real-world settings.

## Next milestones

The project will grow through small, understandable experiments rather than trying to reproduce a specific research paper or job description.

1. Improve the demonstration dataset with topic-matched human/AI examples.
2. Compare a few classical models and feature combinations.
3. Add transformer-based sentence embeddings as a modern representation.
4. Test how results change with text length and topic.
5. Add a short experiment report documenting results, limitations and observations.

## Limitations

Text-generation detection is difficult. Models can learn shortcuts from topic, vocabulary, text length or dataset construction instead of genuinely learning whether a passage was generated by AI. A useful experiment therefore needs matched data, clear evaluation and honest discussion of failure cases.

The project deliberately avoids claiming that a prediction proves authorship or identifies a specific language model.
